# گزارش مقایسه React و Next — ۲۷ اکتبر ۲۰۲۶

مرجع این بررسی `reactversion.zip` در ریشه پروژه بود. آرشیو تغییر نکرده است. نسخه استخراج‌شده برای اجرا و مقایسه در پوشه نادیده‌گرفته‌شده `reports/browser/react-reference` قرار دارد. تغییرات اجرایی فقط در نسخه Next اعمال شده‌اند.

اثر انگشت SHA-256 آرشیو:

```text
44d7502b0bd057102ef17a06ff192492c071776ca012ab13bdf94cef9c0d3988
```

۱۲۴ فایل JavaScript، JSX و CSS مرجع بررسی شدند. در مقایسه اولیه، پس از یکسان‌سازی تفاوت‌های import مسیریابی، دستور client و نام متغیر محیطی، ۹۳ فایل هم‌ارز بودند؛ تفاوت‌ها و جایگزین‌های ۳۱ مورد دیگر جداگانه بررسی شدند. این بررسی شامل componentها، صفحه‌ها، hookها، serviceها، احراز هویت، pagination، فرم‌ها، uploader و پلیر بود. تمام ۴۵ فایل عمومی و asset مرجع، شامل فونت‌ها، لوگوها و تصاویر، در Next بایت‌به‌بایت یکسان‌اند. هر ۱۹ مسیر فعال React در App Router معادل دارد.

نتایج ماشین‌خوان در [parity-validation.json](parity-validation.json)، [parity-playlists-validation.json](parity-playlists-validation.json) و [routes-validation.json](routes-validation.json) ثبت شده‌اند. تصاویر و جزئیات مقایسه سورس و assetها در `reports/browser/` هستند.

- مجموعه اصلی مرورگر: ۵۳ بررسی موفق روی خروجی production و مرجع React، بدون page error.
- مجموعه تکمیلی پلی‌لیست و پلیر: ۵ بررسی.
- HTTP، SSR، canonical، noindex، ۴۰۴، manifest، robots و sitemap: ۲۵ بررسی.
- آزمون‌های واحد: ۵ آزمون موفق.
- build نهایی: موفق.
- lint کل پروژه: صفر خطا و ۵۹ هشدار موجود؛ lint فایل‌های تغییرکرده: بدون خطا یا هشدار.

این تأیید شامل ارسال واقعی OTP، ورود با حساب واقعی، آپلود کامل ویدیو، تغییر رمز، ذخیره تنظیمات و ایجاد/ویرایش/حذف واقعی روی بک‌اند نیست. پنل‌ها با fixture تست شدند. پاسخ ویدیوهای نمونه `video_links` خالی داشت؛ انتخاب چند کیفیت و دانلود کامل فایل در مرورگر تأیید نشده‌اند. نصب PWA و رفتار مرورگر واقعی iOS نیز پوشش داده نشده است. یکسان بودن سورس این بخش‌ها جایگزین تست عملی با حساب و داده مناسب نیست.

برای تکرار مجموعه مرورگر، Chrome و سرور در حال اجرای Next لازم است:

```powershell
npm run dev
# در ترمینال دیگر:
npm run test:parity
```

برای مقایسه هم‌زمان با React، نسخه استخراج‌شده مرجع را جداگانه اجرا کنید و آدرسش را بدهید. `TEST_BASE_URL` نیز آدرس Next تحت تست را تعیین می‌کند:

```powershell
$env:TEST_BASE_URL='http://localhost:3011'
$env:REACT_BASE_URL='http://localhost:4173'
npm run test:parity
```

مهارت Computer Use خوانده و راه‌اندازی آن امتحان شد، اما runtime ویندوز پیش از اجرا با خطای `windows sandbox failed: helper_unknown_error: setup refresh had errors` متوقف شد. تست‌های مرورگر با Playwright و Chrome محلی اجرا شدند.
